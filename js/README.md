# JavaScript (JS) ⚙️

This folder contains the JavaScript code that makes StudyBH work.

JavaScript controls things like navigation, lessons, quizzes, XP, and progress.

## 📁 Files

| File / Folder | What it's for |
|---|---|
| `app.js` | Main website functionality and navigation |
| `engine.js` | Quiz system, XP, streaks, and progress |
| `subjects/` | Subject lessons and questions |

## 📚 Subjects

The `subjects/` folder contains the content for each subject.

| File | Subject |
|---|---|
| `math151.js` | Mathematics |
| `biology102.js` | Biology |
| `chemistry102.js` | Chemistry |
| `physics102.js` | Physics |

## 🤝 Contributing

When working on JavaScript:

- Add new subject content in the relevant subject file.
- Keep lessons organized.
- Don't put everything into one file.
- Check that your changes work before submitting them.
- If you're unsure where something belongs, ask first.

**Tip:** If you're adding a new lesson, check how the existing lessons are written and follow the same structure.

Let's keep the code organized.
