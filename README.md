# StudyBH 🇧🇭

A free educational platform helping Bahraini students access study resources.

🌐 **Website:** https://studybh.github.io/

## What is StudyBH?

StudyBH is a website we're building to help Bahraini students find study materials, explanations, and other useful resources.

## Project Structure

| File / Folder | What it's for |
|---|---|
| `index.html` | Main website code |
| `css/` | Website design and colors |
| `js/` | Website functionality |
| `js/subjects/` | Lessons and subject content |
| `CONTRIBUTING.md` | Contribution guidelines |

## How to Contribute

- Check the GitHub **Issues** tab for suggestions and tasks.
- Make changes to the relevant files.
- Test your changes before submitting them.
- Let the team know what you changed.

## Important

- Keep the code organized.
- Don't edit files that aren't related to your task.
- If you're unsure about something, ask before changing it.

That's it.
